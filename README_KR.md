# 크레이지아케이드 (Crazy Arcade (BnB))

물풍선으로 상대를 가두는 PC 온라인 액션 게임

> **경고: Lab Track 참가 승인을 받은 창작자만 이용할 수 있습니다.** 승인받지 않은 사내 제작, 학습, 연구, 개인 공부, 상업 등 목적과 관계없이 모든 이용을 제한합니다.

> 이용 조건은 저장소 루트의 [LICENSE](LICENSE) 와 [NOTICE](NOTICE) 를 따릅니다. 뷰어: [이 게임을 뷰어로 보기](https://nexon-replay.github.io/Boomhill/#/g/bnb). 세계관과 다른 게임은 [허브](https://nexon-replay.github.io/Boomhill/)에 있습니다.

## 폴더

| 폴더 | 내용 |
|---|---|
| `2d/` | 2D 그림: 묶음마다 폴더 하나, 그림은 PNG(여러 프레임이면 스프라이트 시트)와 아틀라스 JSON |
| `2d/manifest.json` | 파일마다 크기와 SHA-256 |
